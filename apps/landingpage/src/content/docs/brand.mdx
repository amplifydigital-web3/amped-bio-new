Use the name and mark exactly as written so users recognize the account they are signing in with. The name
is always **Amped.Bio**, with a capital B.

## The button

Two variants. Use the filled button on light backgrounds and the outline button where a filled button would
compete with your own primary action. Download the button you ship and the mark below.

{{BRAND_BUTTONS}}

## Button copy

- **Do** use "Sign in with Amped.Bio" or "Continue with Amped.Bio".
- **Do not** use "Login with Amped", "Amped login", "amped.bio OAuth" or translated variants.

## Colors

| Usage                        | Value                           | Contrast                            |
| ---------------------------- | ------------------------------- | ----------------------------------- |
| Filled button background     | `#5650A2`                       | White label and mark measure 6.85:1 |
| Filled button label and mark | `#FFFFFF`                       |                                     |
| Outline button background    | `#FFFFFF`                       |                                     |
| Outline button label         | `#16152B`                       | 17.85:1 on white                    |
| Outline button ring          | `rgba(22, 21, 43, 0.18)`, 1.5px |                                     |
| Outline button mark          | The color mark                  |                                     |

Both buttons are at least 44px high with a 13px corner radius.

## Consent screen

Our consent screen is hosted by us and cannot be restyled. You may show your own explanation of what you do
with the data before redirecting, but you must not ask users to hand over their Amped.Bio password anywhere
except on our own pages.
